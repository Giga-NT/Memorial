# Memorial — 3D-конструктор памятников

Веб-приложение для создания и предварительного расчёта мемориальных комплексов с интерактивной 3D-визуализацией.

## Требования

- Node.js 20 или новее
- npm
- SQLite-файл приложения в `storage/database.db` (инициализируется сервером при первом запуске)

## Установка и запуск

```bash
npm install
npm start
```

По умолчанию сервер запускается на порту `3000`. Порт можно изменить переменной окружения `PORT`.

## Переменные окружения

Создайте локальный файл `.env` и задайте как минимум:

- `ADMIN_PASSWORD` — пароль администратора.
- `EMAIL_USER` и `EMAIL_PASS` — учётные данные почты, если нужна отправка писем.
- `PORT` — порт сервера (необязательно, по умолчанию `3000`).
- `DB_PATH` — путь к SQLite (необязательно, по умолчанию `storage/database.db`).

Не добавляйте `.env`, пароли или рабочую базу данных в Git.

## Тесты

```bash
npm test
npm run test:verbose
```

Текущий набор содержит преимущественно модульные проверки и моки; успешный запуск тестов сам по себе не заменяет проверку приложения в браузере и проверку 3D-сцены.
