Калькулятор считает установку стелы и тумбы отдельно для каждого комплекта. Установка цветника рассчитывается по суммарному периметру цветников. Переключатель выше включает или исключает обе услуги из сметы.
Отметьте позиции, для которых нулевая цена задана намеренно: в смете она останется 0 ₽. Без отметки ноль считается незаданной ценой и отображается как предупреждение. Для большинства позиций флажок управляет предупреждением в админке. Для фотографии он также фиксирует нулевую цену и отключает резервное старое значение.

Здесь задаются цены для клиента. Для основной стелы достаточно одной базовой позиции на материал: укажите ширину, высоту, толщину и цену. Стоимость других размеров калькулятор пересчитает по объёму. Дополнительные изделия добавляйте отдельными позициями ниже.

Материал

Здесь учитывается себестоимость закупки. Эти значения не участвуют в клиентской смете и не изменяют клиентские цены. Наценка автоматически не применяется. Отсутствующие строки не удаляют другие записи.
