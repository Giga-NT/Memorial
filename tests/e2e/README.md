# Браузерные тесты конструктора

Набор использует Puppeteer (уже присутствует в зависимостях проекта) и открывает реальное приложение в Chromium.

## Запуск

В первом терминале запусти приложение:

```powershell
npm start
```

Во втором терминале:

```powershell
npm run test:e2e
```

По умолчанию тестируется `http://127.0.0.1:3000`. Другой адрес можно передать через `TEST_BASE_URL`:

```powershell
$env:TEST_BASE_URL = "http://localhost:3000"
npm run test:e2e
```

Для видимого окна браузера:

```powershell
$env:HEADED = "1"
npm run test:e2e
```

## Что проверяется

- запуск приложения и наличие 3D canvas;
- ввод ФИО и дат;
- переключение основных чекбоксов конфигурации;
- наличие и изменение ползунков;
- загрузка тестового изображения;
- доступность добавления столов, скамеек, пикникового набора и ваз;
- доступность инструментов перемещения и поворота;
- доступность гравировок и эпитафий;
- обработка перетаскивания мышью по canvas;
- переключение освещения и обновление стоимости;
- необработанные JavaScript-ошибки и ошибки консоли.

## Отчёты

После запуска результаты сохраняются в `test-logs/e2e/report.json`. При падении теста рядом сохраняется скриншот страницы.

## Ограничения текущей версии

Это начальный E2E smoke/regression набор, а не доказательство полного соответствия всех пользовательских сценариев. Он проверяет доступность и базовую реакцию интерфейса, но пока не сравнивает точные координаты каждого 3D-объекта, не проверяет все варианты каталога, каждый чекбокс каждого подраздела и полный цикл экспорта/импорта проекта. Эти сценарии следует наращивать отдельными тестами после стабилизации тестовых селекторов и тестового проекта.
